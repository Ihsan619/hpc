# Evidence

This folder is reserved for actual execution evidence. A directory or a plan
is not proof that a task ran.

The validation runner writes task1_validation.json through task4_validation.json
after the corresponding independent checks pass. The Colab notebooks provide
download cells to save these records and real output files locally.

Required screen recordings after successful Colab validation:

- task1_running.mp4: setup, compilation, command-line input, result.txt, PASS.
- task2_running.mp4: requested/capped threads, rectangular/invalid operations,
  results.txt, NaN example, PASS.
- task3_running.mp4: NVIDIA GPU, CUDA compilation, dynamic launch, recovered
  passwords, decrypted.txt, PASS.
- task4_running.mp4: multiple PNG inputs, CUDA launch, source and edge images,
  output PNGs, pixel comparison PASS.

Show the task's notebook title and execution outputs. Record real browser
execution on the student's PC. Do not substitute slides, still images, or
simulated results for the requested recordings.
